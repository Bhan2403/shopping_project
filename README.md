# Shoplytics 🛒

## About the Project
Shoplytics is an interactive shopping analysis dashboard built with Streamlit and Python.  
The project explores customer shopping behavior through various visualizations and data insights.

Users can:
- Explore shopping trends by season
- Analyze product categories and customer preferences
- View payment and shipping methods
- Interact with charts and filters
- Explore customer review ratings

## Technologies Used
- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

## Dataset
The dataset contains shopping behavior information including:
- Age
- Gender
- Purchase Amount
- Product Categories
- Shipping Type
- Review Ratings
- Payment Methods

## Purpose
The purpose of this project is to transform raw shopping data into meaningful and interactive business insights through data visualization.
